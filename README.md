Employee Management Microservices

A complete Spring Boot Microservices application for managing employees
and departments using REST APIs, Eureka Service Discovery, Spring Cloud
API Gateway, OpenFeign, and Resilience4j Circuit Breaker.

Technologies:
- Java
- Spring Boot
- Spring Cloud
- Spring Data JPA
- MySQL
- Eureka Server
- Eureka Client
- Spring Cloud Gateway
- OpenFeign
- Resilience4j
- REST API
- Maven
- Postman
